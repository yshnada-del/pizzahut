# 피자헛 UI 리디자인

기존 HTML / CSS / JavaScript 구성과 로컬 이미지를 사용하는 반응형 사이트입니다.

## 로컬 실행

Node.js가 설치된 환경에서 이 폴더에서 실행하세요.

```sh
node preview.cjs
```

브라우저에서 http://127.0.0.1:5173 으로 접속합니다. 종료는 터미널에서 Ctrl+C입니다. VS Code의 Live Server로 `index.html`을 열어도 됩니다.

## 화면과 동작

- `index.html`: 3초 간격으로 순환하는 배너, 배달·포장 진입, 인기 메뉴, 회원 혜택, 프로모션 안내
- `sub01.html`: 메뉴 이름 검색, 카테고리 필터, 선택한 상품 상세 연결
- `sub02.html?product=0`: 8개 피자의 상품별 상세 화면. 이미지·설명·가격, 사이즈·엣지·수량 선택, 토핑 6종 추가, 추천 사이드 3종의 개별 수량 선택, 선택 내역·합계 및 장바구니 저장
- `login.html`: 입력 안내 및 비회원 메뉴 진입

메인 배너는 1→2→3→1 순서로 반복하며 부드럽게 전환합니다. 일시정지·재생 및 이전·다음 버튼을 제공하고, 마우스를 올리거나 배너 내부 링크에 키보드 포커스가 있을 때는 잠시 멈춥니다. 로그인 카드는 헤더와 푸터 사이의 가로·세로 중앙에 배치됩니다.

메인 인기 메뉴와 전체 메뉴의 피자 이미지·이름은 각 상품의 상세 주소로 바로 연결됩니다. `product=0`부터 `product=7`까지 리얼 BBQ불고기, 베이컨 포테이토, 오리지널 페퍼로니, 슈퍼슈프림, 트러플 머쉬룸 스테이크, 스파이시 바베큐 립, 쉬림프 갈릭 크림, 갈릭 크림 불닭 순서입니다. 상품별로 같은 상세 레이아웃을 사용하며, 메뉴 탐색에서 선택한 배달·포장 방식도 유지합니다.

공통 디자인은 `css/redesign.css`, 화면 동작은 `js/experience.js`에 있습니다. 기존 스타일 파일은 유지했습니다. 메인과 상세는 새 마크업을 사용합니다.

상세 화면의 추가 옵션과 정보 창은 `css/detail-extras.css`, 첨부 디자인을 바탕으로 재구성한 전체 배치는 `css/detail-composition.css`에 있습니다. 토핑·사이드·원산지 자료는 `js/product-details.js`에서 관리합니다. 추가 토핑 금액은 피자 수량에 따라 계산하고, 사이드 수량은 별도로 유지합니다. 추천 사이드와 메뉴 분류에 함께 나타나는 상품은 같은 수량을 공유하며 중복 결제되지 않습니다. 기존 저장 장바구니도 계속 표시합니다.

상세 페이지는 상단 상품·옵션 카드, 하단 여섯 가지 추가 선택 아코디언, 고정 주문 요약으로 구성됩니다. 정보 팝업은 정보 종류(원산지·영양·알레르기)와 메뉴 분류(피자·치킨·파스타&사이드·음료&기타)의 두 단계 탭을 제공합니다. 현재 등록된 상품이 없는 음료·기타 및 플래츠 구매 영역은 빈 상태를 안내합니다.

원산지 정보는 기존 상세 화면의 12개 피자 자료를 복원했습니다. 영양정보와 알레르기 정보는 기존 프로젝트에 실제 수치·성분 목록이 없어 미등록 상태를 표시합니다. 해당 자료가 제공되면 `nutrition`과 `allergens`에 메뉴 이름을 키로 추가할 수 있습니다. 영양정보는 `energy`, `protein`, `saturatedFat`, `sugar`, `sodium`, `serving`을, 알레르기는 성분명 배열을 받습니다.

주소, 주문 방식, 장바구니는 현재 브라우저의 localStorage에만 저장합니다. 실제 주소 검색·매장 조회·회원 인증·쿠폰·주문·결제 API는 연결되지 않은 프런트엔드 데모입니다. 메뉴와 행사 정보는 원본 프로젝트의 예시 자료이며 실제 판매 조건이 아닙니다.
